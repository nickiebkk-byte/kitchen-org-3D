KITCHEN STORAGE 3D — READY TO UPLOAD

1. แตก ZIP จะได้โฟลเดอร์ KITCHEN-STORAGE-3D
2. อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์ โดยให้ index.html อยู่ที่รากเว็บไซต์
3. รักษาโฟลเดอร์ data / icons / ideas และไฟล์ CSS / JS ให้ครบ
4. ไม่ต้องติดตั้ง Node หรือสั่ง build
5. เว็บยังใช้ THREE.JS และฟอนต์ Prompt จากอินเทอร์เน็ตตามระบบเดิม
6. ไอคอน HEADER ใช้ icons/icon-192.png ซึ่งเป็นภาพชุดเดียวกับ Home Screen
7. หากเคยเพิ่ม Home Screen ให้ลบรายการเดิมแล้วเพิ่มใหม่เพื่อเปลี่ยนชื่อที่บันทึกไว้

สิ่งที่ปรับ
- ชื่อ KITCHEN STORAGE 3D และ 3D สีส้ม
- ธีมน้ำเงิน–ส้ม โค้งมน เงานุ่ม และหัวแถบสินค้า/รายการสินค้าสีน้ำเงิน
- ฟอนต์ Prompt และขนาดตามพื้นที่หน้าจอ
- ตรึง HEADER ทุกขนาดจอ
- ตรึงพื้นที่ 2D/3D เมื่อจอแนวตั้งไม่เกิน 1180 พิกเซล
- บนจอแนวตั้งที่สูงไม่เกิน 650 พิกเซล งดตรึงพื้นที่แบบเพื่อให้พื้นที่ใช้งานเพียงพอ
- ชื่อสินค้ายาวคงบรรทัดเดียว สามารถเลื่อนอ่านภายในแถวได้
- รวมไอเดีย 20 ภาพ ข้อมูลสินค้า และไอคอนทุกขนาด

ตรวจสอบ
- สคริปต์ระบบเดิมทั้งหมดเหมือนรุ่นก่อนเปลี่ยนธีม
- ตรวจหน้าเว็บที่กว้าง 390, 820 และ 1363 พิกเซล ไม่มีการล้นหน้าแนวนอน
- ทดลองเลือกสินค้าและนำไอเดียเปิดในแบบ 2D ได้
- การตรึงตรวจในขนาดจำลองผ่านเบราว์เซอร์ ยังไม่ใช่การตรวจเครื่อง iOS จริง
- เบราว์เซอร์ตรวจงานไม่รองรับ WebGL จึงยังยืนยันภาพ 3D จริงไม่ได้

LANDSCAPE UPDATE
- Desktop แสดงสินค้าในแถบด้านขวา เลื่อนแยกจากพื้นที่แบบ
- iPad/iPhone แนวนอน: แบบ 2D/3D ด้านซ้าย สินค้าด้านขวาเลื่อนแยก
- แถบตั้งค่าตู้แนวนอนด้านบนเลื่อนได้เมื่อพื้นที่ไม่พอ
- รูปแบบแนวตั้งคงการตรึงแบบใต้ HEADER ตามเดิม

EXPORT UPDATE
รายการสินค้าที่ใช้อยู่ล่างสุดหลังพื้นที่แบบและแถบสินค้า
ปุ่มส่งออก PNG: ดาวน์โหลดภาพแบบโซนที่กำลังดู พร้อมภาพสินค้า SKU ขนาด และจำนวนรวมทุกโซน
ปุ่มส่งออก PDF: เปิดหน้ารายงานพร้อมภาพและตาราง แล้วเลือกบันทึกเป็น PDF ในหน้าพิมพ์
หากหน้ารายงานไม่เปิด ให้อนุญาตหน้าต่างใหม่ของเว็บไซต์
ส่งออกได้ทั้งมุมมอง 2D และ 3D (3D ต้องใช้อุปกรณ์ที่รองรับ WebGL)
ตรวจดาวน์โหลด PNG และหน้ารายงาน PDF พร้อมภาพ/ตารางในเบราว์เซอร์แล้ว
